📝 Note Backend API

Express.js Backend with Vercel Speed Insights Enabled

🚀 Speed Insights Status

Vercel Speed Insights is now integrated with this application. Performance metrics will be tracked when deployed to Vercel.

The Speed Insights script is loaded at the bottom of this page and will automatically track Core Web Vitals and other performance metrics.

📡 Available API Endpoints:

GET /
POST /note/* (Authentication endpoints)
GET /note/* (Note management endpoints)
💡 Note:

This is a backend API with Speed Insights enabled. To view Speed Insights data:

  1. Deploy this app to Vercel
  2. Enable Speed Insights in your Vercel project dashboard
  3. Visit your deployed site to generate metrics
  4. View the data in the Speed Insights tab
